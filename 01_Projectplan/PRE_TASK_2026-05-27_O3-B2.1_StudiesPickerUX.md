## 2. Kontext

### Vorhandener Code

### file_picker package

`file_picker: ^8.0.0` supports `initialDirectory: String?` auf Desktop (Linux/macOS/Windows). Wenn der Pfad nicht existiert, fällt der Dialog auf den OS-Default zurück — kein crash.

### Schema-Check-Strategie

Nicht `SELECT * FROM studies` mit catch — sondern **defensiv**:

```dart
final tables = await db.rawQuery(
  "SELECT name FROM sqlite_master WHERE type='table' AND name IN ('studies', 'trials')",
);
if (tables.length < 2) {
  throw NotAStudiesDbException(
    'File does not contain expected tables. Found: '
    '${tables.map((r) => r['name']).join(', ')}. '
    'Expected: studies + trials. Pick a file from '
    '01_Projectplan/optimizer_studies/.',
    path: path,
  );
}
```

**Aber Vorsicht:** Wenn die Datei gar keine SQLite-DB ist (falsche Magic-Bytes), wird **schon der `sqlite_master`-Query failen** mit `NOTADB`. Diesen Fall **separat catchen** und in dieselbe `NotAStudiesDbException` wrappen — sonst leakt der Raw-Stack wieder durch.

```dart
Future<void> open(String path) async {
  await close();
  Database? db;
  try {
    db = await databaseFactory.openDatabase(path,
        options: OpenDatabaseOptions(readOnly: true, singleInstance: false));
    final tables = await db.rawQuery(
      "SELECT name FROM sqlite_master "
      "WHERE type='table' AND name IN ('studies', 'trials')",
    );
    if (tables.length < 2) {
      await db.close();
      throw NotAStudiesDbException(
        'Database does not contain studies/trials tables. '
        'Pick a file from 01_Projectplan/optimizer_studies/.',
        path: path,
      );
    }
    _db = db;
    _path = path;
  } on NotAStudiesDbException {
    rethrow;
  } on DatabaseException catch (e, st) {
    await db?.close();
    throw NotAStudiesDbException(
      'File is not a readable SQLite database. '
      'Try a file from 01_Projectplan/optimizer_studies/.',
      path: path,
      cause: e,
      stackTrace: st,
    );
  }
}
```

### initialDirectory-Pfad

Pfad ist projekt-relativ (`01_Projectplan/optimizer_studies/`). Bei `flutter run -d windows` ist `Directory.current` der Projekt-Root. Vorschlag:

```dart
String? _suggestStudiesDir() {
  final candidate = Directory('01_Projectplan/optimizer_studies');
  return candidate.existsSync() ? candidate.absolute.path : null;
}
```

Fallback `null` ist OK — file_picker nutzt dann OS-Default.

### COMMIT B2.1-2: Trial-Detail-Sheet draggable + safe-area

**Files:**
- `lib/ui/widgets/trials_top10_table.dart`:
  - `_openDetail(BuildContext, Trial)` → `showModalBottomSheet` Args erweitern:
    - `isScrollControlled: true`
    - `useSafeArea: true`
    - `constraints: BoxConstraints(maxWidth: 720)` — auf wide-Layouts nicht über die ganze Breite ziehen (sonst sieht das Sheet auf einem 27"-Monitor lächerlich aus)
  - Builder retourniert `DraggableScrollableSheet(initialChildSize: 0.6, minChildSize: 0.3, maxChildSize: 0.95, expand: false, builder: (ctx, scrollCtrl) => _TrialDetailSheet(trial: t, scrollController: scrollCtrl))`
  - `_TrialDetailSheet` Signatur: `final ScrollController? scrollController;` — die innere `ListView` / `SingleChildScrollView` nutzt diesen Controller (sonst funktioniert das Drag-to-Expand nicht — Flutter braucht denselben Controller im Inhalt).
  - Drag-Handle oben im Sheet: `Container(width: 40, height: 4, decoration: BoxDecoration(color: AppColors.divider, borderRadius: BorderRadius.circular(2)))` als visueller Hinweis auf Draggability. Center-aligned, 8px Margin top/bottom.

**Code-Skizze:**
```dart
void _openDetail(BuildContext context, Trial t) {
  showModalBottomSheet<void>(
    context: context,
    backgroundColor: AppColors.surfaceCard,
    isScrollControlled: true,
    useSafeArea: true,
    constraints: const BoxConstraints(maxWidth: 720),
    shape: const RoundedRectangleBorder(
      borderRadius: BorderRadius.vertical(top: Radius.circular(16)),
    ),
    builder: (_) => DraggableScrollableSheet(
      expand: false,
      initialChildSize: 0.6,
      minChildSize: 0.3,
      maxChildSize: 0.95,
      builder: (ctx, scrollCtrl) => _TrialDetailSheet(
        trial: t,
        scrollController: scrollCtrl,
      ),
    ),
  );
}
```

Innerhalb `_TrialDetailSheet.build`:
```dart
Column(
  children: [
    // Drag-Handle
    Container(
      width: 40, height: 4,
      margin: const EdgeInsets.symmetric(vertical: 8),
      decoration: BoxDecoration(
        color: AppColors.divider,
        borderRadius: BorderRadius.circular(2),
      ),
    ),
    Expanded(
      child: ListView(
        controller: widget.scrollController,
        padding: const EdgeInsets.fromLTRB(16, 0, 16, 16),
        children: [ ...header, ...params, ...metrics ],
      ),
    ),
  ],
)
```
